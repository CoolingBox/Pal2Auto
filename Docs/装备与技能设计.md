> 依据：原作招式表（百度百科 / Steam 社区「仙剑奇侠传二 角色技能一览表」/ 巴哈心得）＋
> 素材库 `02_法术特效` `03_物品道具` 里的原始招式与道具名。
> 数值分三类：**有算法** / **[PLACEHOLDER]**（有假设与验证路径）/ **待验证**。

---

## 零、一句话

卡只有四层：**兵器、护具、器物、一次性**。一次性的再分「消耗（本场退场）」与「移除（本局退场）」。
四主角各有偏好体系，**非偏好卡的获取受概率与事件双重限制**（10% + 只在奇遇/黑市出高阶）。

## 一、标签体系（照《大巴扎》）

每张卡带 `Tags`（可多个，逗号分隔），**筛选与偏好判定一律读标签，不读卡名**。

| 维度 | 标签 | 说明 |
| --- | --- | --- |
| 家族 | `Palm` 穿云掌 / `SaberArt` 魔刀 / `Tiger` 虎煞 / `SwordArt` 仙霞剑 / `Formation` 阵术 / `Serpent` 蛇系 / `Fox` 狐系 / `Transform` 变身 / `Spirit` 御灵 / `Incantation` 咒术 / `Ultimate` 绝学 | 只有对应主角的本命卡带 |
| 类型 | `Blade` 兵器 / `Armor` 护具 / `Charm` 法宝 / `Pill` 丹 / `Talisman` 符 / `Dart` 暗器 / `Gu` 蛊 | 商店与奇遇按类型上架 |
| 属性 | `Physical` / `Fire` / `Ice` / `Thunder` / `Poison` / `Heal` / `Shield` / `Pierce` / `Multi` / `Control` / `Expose` / `Haste` / `Freeze` / `Slow` / `Charge` / `HandMod` | 偏好与克制都看它 |
| 节奏 | `Fast` ≤2.2s / `Mid` 2.3–2.8s / `Slow` ≥2.9s | **由 Countdown 自动补**，不用手写 |

`Master` 另存武学归属：0 通用 / 1 小虎 / 2 沈欺霜 / 3 苏媚 / 4 李忆如。
（字段叫 `Master` 而不是 `Owner`：战斗里「谁在出这张牌」用的是另一套概念 `Side` / `DeckBattle` 的 `owner` 参数，同名会看混。）

### 1.1 四层分类与关键词规则

| 层 | 是什么 | 关键词 | 理由 |
| --- | --- | --- | --- |
| **兵器** | 循环输出 | 无（个别带 贯穿/多重） | 靠反复蓄势产生价值 |
| **护具** | 循环防御 | 无 | 同上 |
| **器物** | 被动改规则（上场数、时序） | **消耗** | 用一次就生效，不该反复触发 |
| **一次性 · 丹** | 回血 / 解毒 | **消耗** | 吃完就没了 |
| **一次性 · 符** | 爆发伤害 / 控制 | **消耗** | 符纸烧掉 |
| **一次性 · 暗器** | 穿刺爆发 | **消耗 + 贯穿** | 一次性的穿透 |
| **绝学** | 一局一次的大招 | **移除** | 强到不该回来，逼玩家算账 |
| **蛊 / 毒** | 长期资产（毒层留存） | 无 | 毒是持续状态，不是一次性 |

**两条例外（写清楚，免得后面又反复）**：

1. **金刚符（17）不设消耗**。它是「护体符」，靠反复使用叠护体；一旦消耗，沈欺霜的初始牌（她的 `StarterName` 就是金刚符）打完就没了。
   想统一成消耗，就把她的初始牌换成「软猬甲」—— 但这会改角色起手，需你点头。
2. **冰心咒（14）同理**（解异常 + 护体，靠循环），保持循环。

**现状核对**（`Resources/Config/CardConfig.json`）：

| 类别 | 卡 | 关键词 | 状态 |
| --- | --- | --- | --- |
| 丹 | 金创药 21、还魂香 22、解毒草 23、雄黄酒 24 | 消耗 | **已改完** |
| 攻击符 | 烈火符 11、炎爆 12 | 消耗 | 原本就有 |
| 控制符 | 冰封千里 44、寒冰咒 40 | 消耗 | 原本就有 |

### 1. 王小虎（虎煞 · 穿云掌 / 魔刀）

**原作招式**：
- 穿云掌六式：穿云裂石（单）、覆雨翻云（全）、云起龙骧（单）、烘云托月（全）、拨雨撩云（全）、云出无心（单）
- 魔刀刀法五式：断月波、裂地击、真炎斩（全）、炙天煞（单）、群魔恸（全）
- 辅助：气疗术、元灵归心术、真元护体（增防）、天罡战气（增攻）
- 特技 **虎煞**：虎噬（吞噬积气）、虎啸风生（全）、猛虎出闸（单）、虎踞鲸吞（全）
- 原作装备：**大刀**（中后期换魔刀天吒，25 级）、麻布衣、草鞋

**定位**：慢速高伤 + 高护体，用耐久换爆发。
**独有资源 · 虎煞值**：每次打出「掌法」类卡 +1 层，满 6 层后「虎煞」绝学可用（我们做 1v1，原作靠吞噬低血敌人积累，这里改成按出掌次数积累 —— 否则单场没有「吞噬」这个动作）。

| 项 | 内容 |
| --- | --- |
| 偏好卡类 | 兵器（刀）、护具、器物 |
| 偏好冷却 | **慢（≥2.9 秒）**、单次数值大 |
| 偏好属性 | 贯穿、多重 |
| 非偏好 | 符咒 / 法术、蛊 |
| 签名 5 张 | 虎噬（消耗，+虎煞）、穿云裂石（贯穿）、真炎斩（多重）、真元护体（护体）、天罡战气（增攻） |
| 绝学 | 虎啸风生（移除） |

**独有资源 · 阵位**：场上同时只能有一个阵，打出新阵覆盖旧阵 —— 这是她唯一需要「算时机」的东西。

### 3. 苏媚（蛇系 / 狐系 / 变身）

**原作招式**：
- 蛇系：灵蛇出洞、杯弓蛇影、五蛟灭世（全）
- 狐系：狐御天雷、狐爪碎岩（全）、狐舞动天（全）
- 变身：**化狐**（攻防上升、狐系加强）、**梦蛇**（灵速上升、蛇系加强）
- 控制：回梦（昏睡 5 回合）、鬼降（疯魔 5 回合）、**夺魂（一击毙杀）**
- 辅助：净衣咒（解毒）、凝神归元（治疗）

**定位**：高速上毒 + 控制，脆。
**独有资源 · 变身**：化狐 / 梦蛇各是一种「形态」，持续若干秒，期间改变一整类卡的收益（狐 → 兵器伤害；蛇 → 毒伤）。原作两种形态互斥，我们也互斥。

| 项 | 内容 |
| --- | --- |
| 偏好卡类 | 蛊 / 毒、控制、暗器 |
| 偏好冷却 | **快（≤2.2 秒）** |
| 偏好属性 | 中毒、冰冻（= 原作昏睡）、减手牌 |
| 非偏好 | 护具、慢速大伤 |
| 签名 5 张 | 灵蛇出洞（毒）、杯弓蛇影（按毒层结算）、梦蛇（变身）、回梦（冰冻）、夺魂（移除·斩杀） |

## 三、偏好与获取权重

**偏好不是一个标签，是三个维度**：卡类 × 冷却档 × 属性。

| 来源 | 偏好 | 中立 | 非偏好 |
| --- | --- | --- | --- |
| 集市货架 | 60% | 30% | 10% |
| 遭遇奖励（三选一） | 65% | 25% | 10% |
| 宿敌抢牌 | 60% | 30% | 10% |

**第二道闸：高阶非偏好卡只能从事件出。**
凡品/精品（30/50 两档）各体系都能正常买到；**钻石级以上的非偏好卡**只能通过奇遇的三个专属事件——这是「想玩非主流构筑」唯一的入口，代价是占掉一个时辰。

| 事件 | 给什么 | 代价 |
| --- | --- | --- |
| 师门传授 | 1 张别派「移除」级绝学 + 1 件对应器物 | 无（占一个时辰） |
| 魔功捷径 | 1 张强力非偏好卡（伤害 +30%） | 声望 −2 |
| 异宝现世 | 非偏好体系的钻石器物 | 价格 ×1.5 |

> **你说的「四阿妹」我按「概率低」理解成 10%**。若你的意思是四成，把上表改成 45 / 30 / 25 即可，其余设计不用动。
> 10% 的 rationale：一局摸 12 张卡，期望只有 1.2 张跑偏 —— 刚好够「尝到别派的味道」，不足以让流派模糊。

**2026-11-25 修正：伞是兵器，不是护具。** 原作里青莹石伞 / 紫萝伞 / 菩提宝伞 / 藏星伞 / 符纸伞
都是**武器**（武术 + 灵力 + 防御三条一起加），我们第一版把它们归成了 `Guard`。
现在改成 `Attack` 并保留原作的「攻防兼备」——同一张卡同时给伤害与护体（引擎支持，
和有同样设计的 109 五岳擎天一致）：

| 16 | 青莹石伞 | 铜 | 2.4s | 7 | 4 | 护 8 |
| 118 | 紫萝伞 | 铜 | 3.0s | 9 | 5 | 护 9 |

例外：**204 伞蜘蛛仍是护具**。它不是伞，是「遇风而长、持在手中便如伞具」的蜘蛛，
原作定位是防御装备（武术+6 / 灵力+75 / 防御+42），当成兵器反而不对。
另外敌人牌组（盗王查协）里有 16 号青莹石伞，这一改让他少了 4 点纯护体、多了 7 点攻，
实测同配置战斗时长从 21.5 秒缩到 18.5 秒。

**卡池膨胀的代价与解法**：278 张里通用 204 张，按阶抽会摊薄「想买某一张」的概率。
2026-11-25 已采用两个补法里的第一个：

1. **货架 3 格 → 4 格**（`ShopStock.SlotCount = 4`）。每次刷新多一张同类，凑同名卡做 2 合 1 明显容易了。
   实测（`--runlog`，4 局）合成 5 次/局、余银 37、通关率 50%，与 3 格时基本一致 —— 多一格没有通胀。
2. **分店抽卡本来就在做**：每次进集市先 roll 品类（武学馆 / 兵器 / 护具 / 丹药 / 符咒 / 器物 / 蛊毒 / 法术），
   4 格全部来自这一类的池子，所以「按 tag 分类随机」是真的，同类同阶的候选只有十几到二十几张，
   同一张卡在**不同次刷新**之间反复出现是常态（店内那一次刷新内不重复，`usedIds` 挡掉）。
3. 剩下那条「先按攻/守/疗/毒分组再组内随机」暂不做 —— 分店已经起到同样作用。

### 引擎暂时表达不了的 6 个机制（已用近似实现顶上）

| 原作机制 | 我们的近似 | 要真做需要 |
| --- | --- | --- |
| 增攻 / 增防百分比（天罡战气、真元护体） | 破绽（Expose）/ 护体数值 | 加「伤害乘区」字段 |
| 场地属性（阵术） | 一次性 buff：加速 / 冰冻 / 破绽 | 加「场地」槽位与持续状态 |
| 变身（化狐 / 梦蛇） | 一次性全体加速 + 毒加深 | 加「形态」持续时间与乘区 |
| 昏睡 / 疯魔（回梦 / 鬼降） | 冰冻 / 减速 | 加「无法行动」状态 |
| 一击毙杀（夺魂） | 40 点高伤 + 移除 | 加「斩杀阈值」字段 |
| 御灵契约（往牌组塞卡） | 一次性召唤伤害 | 加「战斗中改牌组」能力 |

这 6 条不是漏做，是**引擎还没这几个概念**；每条都标注了补哪个字段，按重要性排：伤害乘区 > 场地 > 形态 > 状态 > 斩杀 > 改牌组。
