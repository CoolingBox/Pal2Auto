# 卡组战斗：规则定义 v0.1

> 一句话：**牌组是构筑，手牌是自动化产线。** 玩家在战前决定"牌组里放什么"，战斗中由每张牌的倒计时自动出手，打出后立刻补抽。

---

## 1. 与旧方案的关系

| | 旧（大巴扎式摆位） | 新（本方案） |
| --- | --- | --- |
| 载体 | 3×3 摊位格，物件常驻 | 牌组 → 手牌 5 张，打出即进弃牌堆 |
| 决策点 | 摆位（相邻连携） | 组牌（张数配比 / 费用曲线 / 触发节奏） |
| 战斗内操作 | 无 | **无**（双方全自动，玩家只看） |

保留大巴扎的"自动出手"内核，把"位置"换成"牌序与手牌"，接上杀戮尖塔的构筑：**战前组牌，战中看戏。**

---

## 2. 回合结构

1. 战斗开始：从抽牌堆抽 **5** 张进手牌（手牌上限固定 5）。
2. 每张手牌各自有一个**蓄势倒计时**（卡面左下角的秒数），入场即满值开始走。
3. 倒计时归零 → **自动打出** → 进弃牌堆 → **立刻**从抽牌堆抽 1 张补进该空位（新牌从满倒计时开始）。
4. 抽牌堆抽空 → 把弃牌堆洗回抽牌堆再抽；两边都空 → 该位空着不补（手牌会变少，直到有牌洗回）。

> 手牌 5 个"槽位"是固定的，补抽只补到空位，不改变槽位顺序——这样玩家能看出"哪张牌快出手了"。

## 3. 结算

- 双方同时推进，伤害/护盾即时结算。
- 玩家气血归零 → 败；敌方气血归零 → 胜；60 秒未分 → 按剩余气血比例判。
- 中毒：每层每秒 **0.5** 点（2026-11-24 从 1.0 下调），**无视护体**（`TickPoison` 直接扣血，原文档写「护盾可吸收」与代码不符，已改正）。层数上限 20（`DeckBattle.PoisonMaxStacks`），不随时间衰减。
- 护体上限 20：不加限制的话守牌会把伤害全吃掉，双方都打不死，战斗变成看血条不动。
- 无视护盾的牌（暗器/法术）直接扣气血。

## 3.5 战斗界面与交手记录

**版面：上下对峙。** 敌手在上、我方在下，两排牌阵夹在中间（上排敌方小卡，下排我方大卡），
牌阵与角色之间留出飘字的位置。这样"谁在打谁"不需要读文字：上方掉血就是敌方挨打。

**卡面：数值优先。** 效果数值（攻/术/守/疗/毒/破）字号 18，倒计时 30 并带"蓄势"小标题；
效果标签按卡牌定位取色、居中并排，复合牌（如 `守 4 疗 8`）直接看出两件事。

**头像框 v3：老游戏质感（硬倒角，不做渐变）。** 第一版是一条均匀金边（平得像塑料贴片），
第二版改成"抛光金属"——渐变框面、拉丝、内倒角亮圈、白色内亮线、宝石带高光。技术上成立，
但那是手游做法：满屏反光，看着"新"。v3 反过来，**层与层之间只隔 1~2 像素、硬切换**：

| 层 | 颜色（主色的倍数） |
| --- | --- |
| 外投影 | 1px 硬边，黑 55%（不做柔光晕） |
| 外沿暗线 | ×0.30 |
| 外倒角 | 受光 ×1.12 / 背光 ×0.50 |
| 主框面 | 平色：受光 ×0.94 / 背光 ×0.76 |
| 内倒角 | 受光 ×1.04 / 背光 ×0.58 |
| 内沿暗线 | ×0.34 |
| 内圈暗缝 | ×0.38 —— **暗缝，不是亮线**（亮线在暗底上就是反光） |

受光判定用距离场梯度当法线，只取两档不插值。角饰是方形铆片（往里收 0.050），
宝石做小做暗、去掉高光点，只保留"分辨敌我"这一个功能。
一句话总结这次的取舍：**能用一道暗线交代的厚度，不要用渐变去糊。**

立绘不按"铺满裁切"（那是第一版的做法：从中间裁，结果**头全被切掉**），改成**按内容对齐**：
先取不透明像素的包围盒去掉四周透明留白，再把整张立绘塞进框内可见区（外框 + 内圈亮线以内），
**上沿留一条缝**——仙剑2 的立绘头部都顶在图的最上沿，居中或顶格裁都必然切到头。
立绘比框高时只从下摆裁（胸以下压到框边下面），至少露出内容高度的 63%，宽度尽量撑满；
比框窄的（瘦身型立绘）两侧留给暖暗底色，不用虚化立绘当衬底——那样头顶会糊成一片，看着还是像被切了。
敌我用两种金、两颗不同色的宝石（敌方赤、我方青）区分，扫一眼就知道谁是谁。

**卡牌：敌我同一套外观、同一套尺寸规则。** 张数相同时两边尺寸完全一致；
张数变多（器物加槽位）时整排按行宽反算缩小，字号跟着缩，最小不低于基准的 62%，再小汉字就糊了。

牌面不再是"纯色圆角矩形 + 1px 边框"（那是 StyleBoxFlat 的极限，平得像便利贴），改成一个卡面着色器：
外 1px 暗线 → 1px 主色细线 → 平色牌面（暗纸混主色 6%）→ 内 1px 主色细线 → 底部凹槽 + 进度条。
圆角只留 2px（老界面基本是直角）；边框只留一条 1px 主色线，2px 亮框就是霓虹灯。
空格位把面色压到 0.78、内框线改虚线；物品图标统一裁成圆牌并整体压暗到 0.74
（素材本来就是方形画布里的圆形玉牌，米色原画是卡面上最闪的一块）。

> 颜色空间：Godot 4 的 2D 是线性空间出图，着色器里写死的 `vec3(0.098)` 是线性值，
> 屏幕上会变成 0.33 的浅灰。底色一律走 `source_color` 的 uniform —— 这条踩过，整张卡发白。

**牌堆：双方各有抽牌堆与弃牌堆。** 敌方两堆贴在敌方信息栏右侧，我方两堆贴在我方信息栏右侧，
各自显示剩余张数，空堆的 0 会转灰。抽牌堆**不露牌面**——牌序是内核决定的，露出来等于剧透；
弃牌堆把最后进去那张的图标压到 32% 不透明度当底纹，一瞥就知道刚弃了什么。
牌堆画成三层错位的纸（+6 / +3 / 0）来交代"一叠"，最上层带主色边框和内圈细线，和卡面同一套语言。
鼠标悬停任一牌堆，提示里列出这一堆的完整牌名。

**血条：凹槽 + 填充 + 高光三件套。** 近黑凹槽带 1px 暗金边，填充顶边压一道亮线当高光；
血量数字**不放进条里**——11px 白字压在实心红条上会糊成一团，挪到名字那一行的右端（名左数右）。

**交手记录：可选抽屉，默认关闭。** 右上角「交战记录」开关，状态写进 `SettingData.BattleLogEnabled`，
开一次下次进战斗仍然开着。关着是因为抽屉会盖住左侧两张牌——它是查账工具，不是常驻面板。

抽屉两页：

| 页 | 内容 |
| --- | --- |
| 明细 | 逐行：`时间  谁  牌名 → 效果`。例：`5.4s  敌「柳叶刀」→ -0(挡 6)`、`5.5s  你「金创药」→ +4护  +8气` |
| 统计 | 双方汇总：出手次数、均伤、直伤、承伤、护体、回复、毒伤、破绽、首手时间、残血 |

**统计规则（避免"数字对不上"）**：

- **直伤**只算扣到气血的部分，被护体挡掉的不算；被挡多少单独写在该行的 `挡 N`。
- **护体**只记实际上限内拿到的量：已经 20 点满值时打出守牌，记录写 `+0护`，不写 `+8护`。
- **毒伤**独立成栏，不并入直伤——否则"造成 133 却输了"会看起来像算错。
- **首手** = 本方第一张牌打出的时刻，用来对比两边节奏快慢。

## 4. 敌方（同样是牌组）

敌我不再是"牌组 vs 行动条"，双方跑**同一套规则**：5 张手牌、独立倒计时、打出补抽、弃牌堆洗回。

| 项 | 玩家 | 敌方 |
| --- | --- | --- |
| 手牌 | 5 张（大卡） | 5 张（小卡） |
| 牌组 | 12 张（当前固定，待做构筑） | 8 张，写在 `EnemyConfig.json` |
| 气血 | 260 + 14×(等级-1) + 铁骨奖励（`RunState.MaxHp`） | 按天数算（`RunState.DayBaseHp`，第 1 天 110） |
| 出牌逻辑 | 完全相同 | 完全相同 |

- 敌方牌组示例（盗王查协）：飞蝗石 ×2、长剑、油纸伞、柳叶刀 ×2、蛇涎蛊、金创药——**快牌多、带毒、有一张护体**
- UI 上敌方手牌用小卡显示图标 / 名字 / 倒计时 / 效果色点，右侧写"下一手：最先归零的那张"
- 敌我的胜负完全由"牌组配比 + 倒计时方差"决定，没有隐藏的AI偏袒

> 为什么改成对称：不对称的两套系统（一边牌组一边行动条）会让玩家没法用同一套直觉去预判对手，"它在干什么"永远说不清。对称之后，看敌方小卡就知道它下一手要做什么。

## 5.1 破绽

`破 N` 给目标叠 N 层破绽，每层使其**受到的所有伤害 +15%**，最多 3 层，4 秒后清零。
设计意图：给"慢重牌"一个前置——判官笔先点伤，长鞭/精铁剑再吃这口增伤。

## 5.15 上场数（6 张器物）

手牌槽位不是恒定的 5 个：**基础 5，上限 8，下限 1**。器物牌可以让它临时或本场变化，
目标可以是自己、对方或双方。

| 牌 | 效果 | 蓄势 | 持续 |
| --- | --- | --- | --- |
| 乱神散 | 敌 -1 | 3.6s | 6 秒 |
| 袖里乾坤 | 我 +1 | 4.0s | 本场 |
| 缚手咒 | 敌 -1 | 4.2s | 本场 |
| 急就章 | 我 +2 | 4.6s | 5 秒 |
| 聚宝盆 | 双方 +1 | 4.8s | 10 秒 |
| 分身符 | 双方 +1 | 5.2s | 本场 |

**为什么都这么慢**：槽位就是每秒出手次数，5→6 等于凭空 +20% 产能，比任何单张伤害牌都硬。
所以定了两条定价规则：

1. **本场持续的，比限时的慢**——一次投入打完全场，价值随战斗时长线性上涨。
2. **加得多的，比加得少的慢**——`+2` 的急就章（4.6s）比 `+1` 的袖里乾坤（4.0s）慢；
   同时影响双方的（分身符 5.2s）比只影响一边的慢。

规则细节：

- **加槽位**：新槽位立刻补抽一张（从抽牌堆，空则洗回弃牌堆）。
- **减槽位**：被砍掉的槽位里的牌**进弃牌堆**，不是消失。
- **限时到期不立刻收**：时间到了先挂一个"待收"标记，**等这一方打出下一张牌时才真正减**。
  理由是一到期就抽走牌，玩家会觉得"我什么都没干，位置就少了一个"，正要出手的那张牌也跟着没——
  像被系统抢了一下。界面上会写 `上场 7（待收）`，收掉时记录写 `9.8s 你 限时到期 → 上场 6`。
- **收回量按当时实际加上去的量**：顶到上限时只加了 1，就只收回 1。

## 5.18 关键字

一张牌可以同时带多个关键字（位标记）。卡面左上角用单字角标显示，悬停有完整说明。

| 关键字 | 角标 | 规则 |
| --- | --- | --- |
| 消耗 | 耗 | 打完进**消耗堆**，本场不再洗回牌库。手牌会越打越薄，这是"快攻流"的代价 |
| 移除 | 移 | 打完从牌库**永久**去掉，写进 `DeckProgress` 存档，下一场也不会再出现 |
| 贯穿 | 穿 | 无视护体，直接扣气血（原来的 IgnoreShield 并入这里） |

带关键字的牌：

| 关键字 | 牌 |
| --- | --- |
| 消耗（11 张） | 烈火符、炎爆、金创药、还魂香、化尸水，以及全部 6 张器物（袖里乾坤、分身符、缚手咒、急就章、乱神散、聚宝盆） |
| 移除（1 张） | 摄魂铃——铃响一次就碎，换 18 点伤害 |
| 贯穿（1 张） | 梅花镖 |

**消耗为什么要给器物牌**：上场数是本作最硬的旋钮（见 5.15），如果器物牌能反复洗回，
一份牌组就能无限往上叠槽位。加上「消耗」之后每份器物本场只能用一次，
既保住了强度，又不至于失控——实测把沈欺霜从 83% 压到 33%、苏媚从 100% 压到 73%。

**移除的代价**：目前没有构筑界面，也没有回收途径，所以只给了一张（摄魂铃）。
调试时用 `--resetdeck` 复原。

## 5.19 时机关键字（加速 / 减速 / 冰冻 / 充能 / 多重）

### 一条新的基础规则：用牌要喘气

每次使用一张牌，那个槽位进入 **0.25 秒补抽冷却**，冷却走完才补下一张。
多重牌按结算次数累加：多重 2 = 0.5 秒。所以"多重"不是白送的伤害，它换的是回收速度。

这条规则让"手牌 5 张"不再是 5 条独立的生产线，而是一组会互相等待的节拍器——
手牌越多收益越明显，但也更容易被"用一张喘一口气"拖住。

| 关键字 | 效果 | 卡面写法 |
| --- | --- | --- |
| 加速 | 指定范围内随机 X 张牌，蓄势速度 ×2，持续 Y 秒 | 我速2·6s |
| 充能 | 指定范围内随机 X 张牌，蓄势立刻前进 1 秒（冰冻中也生效） | 我充3 |
| 减速 | 指定范围内随机 X 张牌，蓄势速度 ×0.5，持续 Y 秒 | 敌缓2·5s |
| 冰冻 | 指定范围内随机 X 张牌，Y 秒内不能自然蓄势，化冻后才能打出 | 敌冻2·4s |
| 多重 | 这张牌每次使用结算 X 次 | 重2 |

### 作用范围（每张牌自己定）

`Scope` 字段决定打给谁，卡面标签的第一个字就写着，不用记规则：

| Scope | 卡面写法 | 含义 |
| --- | --- | --- |
| `Self` | `我速2·6s` | 只作用于自己 |
| `Foe` | `敌冻2·4s` | 只作用于对方 |
| `Both` | `双缓全·4s` | 双方各取一份 |

**张数写 0 就是"全体"**：`我速全·5s` = 我方全体牌，不随机挑，全给。
所以同一套字段能表达"我方随机 2 张""敌方全体""双方各 3 张"这些组合，不用为每种情况加字段。

**打出的那张牌永远不参与**——否则一张加速符会先给自己加速，然后立刻被消耗掉，白给。

**为什么默认是"我加速 / 敌减速"**：加速是"我快"，它的反面自然是"你慢"。
早期我把减速也做成作用于自己，沈欺霜（带寒冰咒）直接 0% 胜率——一张自残牌没人会带。
所以归属按"它该帮谁"定，而不是按字面对称。

**加速与减速抵消**：速度倍率相乘。同时挂上时 2 × 0.5 = 1，正好回到原速。
所以"你先加速、我后减速"是一场可以互相拆招的对抗，而不是各算各的。

**冰冻与充能的关系**：冰冻挡住的是"自然蓄势"，挡不住"充能"——充能直接改蓄势条。
但化冻前即使蓄势归零也打不出，得等冰冻结束。这给了一个组合：先冻住对面的关键牌，
再用充能把它推到临界，化冻瞬间连打。

**随机取牌**：加速/减速/冰冻/充能都从"当前有牌的槽位"里随机挑，排除正在打出的这一张，
张数不足时按实际有的张数生效，不空放。

| 冰封千里 | 冻 全体 · 3 秒 | 双方 | 牌池（见下） |

**冰封千里为什么不进牌组**：它是"双方全体冻结 3 秒"，对拼伤害的牌组是纯亏——
对面少打 3 秒，你也少打 3 秒，但需要靠持续输出取胜的一方亏得更多。
实测把它塞进沈欺霜的牌组，胜率从 62% 掉到 35%（60 场）。所以它留在牌池当情境牌，
等以后有"靠毒/靠护体磨"的构筑再用。

## 7. 实测平衡（`--sim=60`）

敌方盗王查协：气血 140、9 张牌、带一张「聚宝盆」。

| 侠客 | 胜率 | 均时 | 观察 |
| --- | --- | --- | --- |
| 王小虎 | 60% | 11.4s | 号令三军（我方全体加速）是他的提速点 |
| 沈欺霜 | 62% | 21.9s | 寒冰咒冻对面两张，靠拖时间赢 |
| 苏媚 | 90% | 11.1s | **仍是最强**：蛊毒 + 缚足钉双减益 |
| 李忆如 | 60% | 12.4s | 只剩一张功能牌（惊雷令），伤害密度够了 |

**这一轮反复验证到的一条规律**：功能牌会稀释伤害密度，掉得比想象中狠。

- 惊雷令最初没有伤害，李忆如 40% → 23%；补 8 点雷伤后回到 57%。
- 李忆如再加一张纯功能的疾风符，即使牌池降到 14 张也只到 35%；
  把它退回牌池后回到 **60%**。
- 冰封千里（双方全体冻结）同样：进牌组 35%，退回牌池 62%。

结论：**在"只比谁先打死谁"的框架里，不带伤害的牌必须自己创造节奏优势**，
否则就是纯粹的拖累。这也意味着以后做"纯功能牌"要配一条别的东西（抽牌、减蓄势、护体）来补偿。
